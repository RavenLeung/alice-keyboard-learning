# 无线方案对比：蓝牙 vs 2.4G USB

## 结论先行

- **打游戏（尤其竞技类）→ 选 2.4G USB**
- **办公、多设备切换、便携 → 选蓝牙（或优先三模键盘）**
- **最优解：三模键盘（有线 + 2.4G + 蓝牙），按场景切换**

## 2.4G USB（接收器方案）

**优点：**
- 延迟极低：主流电竞键盘 1ms 级轮询率（罗技 Lightspeed、雷蛇 HyperSpeed 等私有协议），接近有线
- 稳定：私有协议、专属信道，抗干扰强，基本不丢帧不连击
- 即插即用：插上就能用，无需配对

**缺点：**
- 占用一个 USB 口
- 接收器容易丢（选有磁吸收纳仓的）
- 换设备要拔插接收器

## 蓝牙（Bluetooth）

**优点：**
- 不占 USB 口，无接收器
- 多设备快速切换：一般支持记忆 3 个设备，一键切换，办公神器
- 便携，出差不用带接收器

**缺点：**
- 延迟明显更高：普通蓝牙 HID 延迟 10–20ms+，低功耗模式更慢；蓝牙 5.1/5.2 后改善但仍不如 2.4G 私有协议
- 稳定性看环境：USB 3.0、2.4G WiFi、其他蓝牙设备都可能干扰，偶发连击/卡顿
- 唤醒延迟：休眠唤醒约 1 秒，第一下按键可能没反应（部分键盘可关休眠）

## 场景选择表

| 场景 | 推荐 |
|---|---|
| FPS/MOBA 等竞技游戏 | 2.4G（甚至直接有线） |
| 办公码字、多设备切换 | 蓝牙 |
| 两者都要 | 三模键盘，游戏切 2.4G，办公切蓝牙 |
| 预算有限 | 优先 2.4G 单模或三模入门款 |

## 小建议

1. 认准**三模**（有线 + 2.4G + 蓝牙）
2. 电竞键盘看是否标注 1ms 低延迟 / 1000Hz 轮询率（蓝牙一般做不到）
3. 蓝牙为主优先蓝牙 5.0+ 且支持多设备快速切换的型号
4. 2.4G 键盘注意接收器收纳设计
