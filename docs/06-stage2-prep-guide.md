## 一、二极管的作用（防鬼键 / 支持多键同按）

### 1.1 为什么键盘用矩阵

84 键若每键一根线 → 84+ 根线。矩阵方案：排成**行 × 列**（如 6×14），每颗键在交叉点
→ 只需 20 根线。主控轮流给列通电、读行信号。

### 1.2 没有二极管 = 鬼键（Ghosting）

同时按 A、B、C 三键时，电流可能从 B 经 A 的交叉点"倒灌"到另一行，导致主控误以为
没按的 D 也被按下。这就是鬼键——游戏中多触发键位、角色乱跑的元凶。

```
  列1   列2
行1 [A]  [B]    同时按 A、B、C
行2 [C]  [D]    → 电流倒灌，D 被误触发 ✗
```

### 1.3 二极管 = 单向阀

每颗轴串一颗 1N4148，只允许电流**列 → 行**单向流动，倒灌被挡死 → 无鬼键，
支持多键同按（NKRO）。

**焊接要点**：二极管有方向（看丝印横杠 / 万用表蜂鸣档），焊反该键不工作。
1N4148 便宜（100 颗几块钱），焊错换一颗就是。

## 二、RP2040-Plus 引脚规划

### 2.1 板子规格（Core Electronics，A$12.60）

| 项目 | 值 |
|---|---|
| 芯片 | RP2040（树莓派官方 MCU，QMK 支持成熟） |
| 接口 | USB-C（比原版 Pico 的 Micro-USB 好） |
| Flash | 16MB（原版 2MB，空间绰绰有余） |
| GPIO | 26 个（GPIO0–22 + GPIO26–28，后者兼 ADC） |
| 编程 | UF2 拖拽 + BOOTSEL 按钮（几乎刷不坏） |
| 引脚兼容 | 与 Raspberry Pi Pico 完全兼容（教程通用） |

### 2.2 矩阵占用计算

```
Alice 规划矩阵：6 行 × 12 列 = 18 个 GPIO
剩余余量：26 − 18 = 8 个 GPIO
  ↳ 旋钮编码器 ×2 / RGB 灯带 ×1 / OLED ×2 / 状态 LED ×1–2
```

对比：经典 Pro Micro 仅 18 GPIO，6×12 刚好用完无余量；RP2040 留升级空间。

## 四、为什么手搓键盘不用 K2 Pro 的配件

| 对比 | K2 Pro（STM32L432） | RP2040-Plus |
|---|---|---|
| 定位 | 商用量产无线键盘 | DIY 开发板 |
| 蓝牙 | 内置（CKBT51 独立芯片） | 无（USB 有线） |
| 功耗优化 | 超低功耗（WFI/LPM） | 一般（插线无所谓） |
| 刷固件 | DFU + dfu-util | UF2 拖拽 |
| 能否拆用 | ❌ MCU 焊死（QFN 封装） | ✅ 直接接线 |

结论：K2 Pro 练固件能力（已打通），RP2040 练焊接+接线；**固件技能完全复用**，
配件互不通用。Alice 目标是 USB 有线单板矩阵，蓝牙/低功耗设计用不上。

## 五、备忘

- 每颗轴 = 1 颗二极管（70 轴 ≈ 70 颗），方向别焊反
- 矩阵编号和物理形状无关，接线只管行列（docs/03 关键提醒）
- 手搓阶段不需要 PCB；打板是阶段 4 升级选项（2 层板够用）
