## 四、接线规划（13 GPIO）

```
矩阵：5 行 × 5 列 = 10 GPIO
  行 R0–R4 → GP0–GP4   （输入，内部上拉）
  列 C0–C4 → GP5–GP9   （输出，轮流拉低扫描）

旋钮：A → GP10，B → GP11，按键 → GP12（公共端接 GND）
```

**按键插法（关键）**：四脚按键跨面包板中间凹槽插——**同侧两脚内部相连**，
上两脚当"列"、下两脚当"行"，每键串一颗 1N4148（列→行方向，防鬼键）。

**布局**：25 键 5×5 正好占满一块 830 孔板中间区（5 排 × 5 键）→
主控和旋钮放第二块板，两板之间杜邦线飞线。

## 五、QMK 配置要点

### 5.1 矩阵定义（info.json 或 config.h）

```
MATRIX_ROWS = 5
MATRIX_COLS = 5
diode_direction = COL2ROW   // 列输出、行输入；二极管方向按接线确认
```

### 5.2 旋钮（照 docs/09）

```make
# rules.mk
ENCODER_ENABLE = yes
ENCODER_MAP_ENABLE = yes
```

```c
// keymap.c
#if defined(ENCODER_MAP_ENABLE)
const uint16_t PROGMEM encoder_map[][NUM_ENCODERS][2] = {
    [0] = { ENC_CCW(KC_VOLD),         ENC_CW(KC_VOLU) },        // 音量
    [1] = { ENC_CCW(KC_MS_WH_DOWN),   ENC_CW(KC_MS_WH_UP) },    // 滚轮 → 达芬奇/LR 滑块
};
#endif
```

### 5.3 调试顺序（每步都好定位问题）

1. 只接旋钮 → 跑通音量 + 滚轮（docs/09 玩法）
2. 只接 5×5 矩阵 → 跑通 QMK 键盘功能
3. 合体 → 层切换 + 旋钮不同层不同功能

## 六、备忘

- 按键同侧两脚内部相连，先拿万用表蜂鸣档确认哪两脚是一组再布线
- 二极管有方向（丝印横杠），焊反/插反该键不工作
- 面包板矩阵编号和物理位置无关，只管行列（docs/03 关键提醒）
- 这块原型机的 QMK 配置骨架，阶段 3 改改矩阵尺寸就是 Alice 的起点
