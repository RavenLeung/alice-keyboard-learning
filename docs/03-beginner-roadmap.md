# 从零开始：USB Alice 键盘练手路线

**定心丸：** QMK 这类键盘固件就是为"不懂嵌入式的人"设计的——主要工作是写配置（引脚、配列），USB HID 协议、矩阵扫描、去抖全部固件代劳。真正要练的硬技能只有两个：**焊接**和**读懂矩阵电路**。

总时间：约 1–2 个月（业余时间）。

## 阶段 0：搞懂原理（1 周，纯看）

- **矩阵**：行 × 列，每颗轴串一颗二极管（1N4148），二极管防"鬼键"并支持多键同按（NKRO）
- **Alice 配列的关键认知**：只是外观有分体弧线，实际是**一整块矩阵、一块电路板**，不需要分体电路 → 按"单板"做
- 认识物料：轴体（MX 类）、二极管、Pro Micro（ATmega32u4，QMK 最常用主控，~¥30）、飞线

## 阶段 1：软件先行（3–5 天，不碰硬件）

1. 装 QMK 命令行：Windows 用 **QMK MSYS**，macOS/Linux 用 pip 装 `qmk`
2. `qmk setup` 后编译现成键盘：`qmk compile -kb crkbd -km default` —— 编译通过 = 环境 OK
3. 用网页版 **QMK Configurator**（config.qmk.fm）拖配列导出固件，零代码感受流程
4. 目标：会编译、会烧录（`qmk flash` + QMK Toolbox）

## 阶段 2：最小焊接闭环（1–2 周）

买最小套装：Pro Micro ×2（备用）、10 颗轴、面包板/洞洞板、二极管若干。

1. 面包板上把几颗轴 + 二极管接成 2×3 小矩阵
2. 写 `handwired` 小固件刷进去
3. 用网页 Keyboard Tester 逐个按键验证
4. 意义：跑通"焊接 → 接线 → 矩阵 → 固件 → 验证"闭环，之后做 Alice 只是规模放大

## 阶段 3：手搓 Alice（2–4 周）

**物料清单（约 ¥150–300）：**
- 主控 Pro Micro（多买 1–2 个备用）
- 1N4148 二极管 ×100（几块钱）
- 轴体 ~70 颗、键帽一套
- 恒温焊台（300–350℃）、助焊剂、飞线
- 定位板/外壳可选（先裸板也行）

### 硬件选购清单（推荐版，2024 建议）

**主控选 RP2040（树莓派 Pico 兼容板）而非 Pro Micro：**

| 对比项 | RP2040 Pico 兼容板 | 经典 Pro Micro |
|---|---|---|
| 价格 | ~¥20–30 | ~¥30 |
| GPIO | 26 个（6×12 矩阵用 18，有余量加旋钮/RGB） | 18 个（6×12 刚好用完） |
| 接口 | USB-C | micro-USB |
| 刷固件 | UF2 拖拽（按住 BOOTSEL 插线 → 拖 .uf2），几乎不可刷坏 | avrdude + 复位时序，新手易卡 |
| 备注 | 教程例子用 Pro Micro 引脚名，但概念相同 | 想 100% 照教程走可选 |

**购物清单：**

| 物料 | 推荐 | 数量 | 预算 |
|---|---|---|---|
| 主控 | RP2040 Pico 兼容板（USB-C 款） | 1–2 块 | ¥30–60 |
| 二极管 | 1N4148 直插 | 100 颗 | ¥5 |
| 轴体 | Gateron 黄轴/茶轴（5-pin） | 先 10 颗试手感，再补 60 颗 | ¥70–100 |
| 键帽 | PBT 108 键 OEM 高度套件 | 1 套 | ¥50–80 |
| 飞线 | 30AWG 镀锡单芯线 | 1 卷 | ¥10 |
| 焊锡 | 含铅 63/37 | 1 卷 | ¥20 |
| 烙铁 | 936 恒温（~¥60）或 T12（~¥120），没有先买 | 1 把 | ¥60–120 |
| 定位板（可选） | 亚克力/3D 打印，先裸焊也行 | 1 张 | ¥30–60 |

**购买顺序：**
1. 第一单：主控 ×2 + 二极管 + 轴 10 颗 + 面包板（阶段 2 最小练习套装，~¥100）
2. 第二单：试完手感补轴 60 颗 + 键帽 + 飞线 + 焊锡
3. 定位板/外壳：矩阵和固件跑通后再买

**步骤：**
1. 定矩阵：如 6 行 × 12 列，画"哪个引脚接哪行哪列"的表
2. 焊接：每颗轴焊一个二极管，按行列连成网（弧线不影响接线）
3. 建固件：`qmk new-keyboard` 生成 `handwired/名字`，`info.json` 填行列引脚，`keymap.c` 用 `LAYOUT` 宏定义 Alice 配列（可抄 QMK 里现有 Alice 类键盘）
4. `qmk compile` → `qmk flash`，**每焊一排就测一排**

## 阶段 4：进阶（可选）

- 加 **VIA** 支持（免编译改键位）、旋钮编码器、OLED、RGB
- 学 PCB 设计：**立创EDA 专业版**（免费，国内打样方便，[官网](https://lceda.cn)）或 **KiCad**（国际社区标准，键盘教程最多，如 ai03 教程）
- 嘉立创打样几块钱一张，可参考 GitHub 开源 Alice PCB 设计直接改
- 注意：手搓阶段不需要 PCB；这是后续升级选项

## 关键提醒

- **先软件后硬件**：先保证"现成固件能编译能刷"，再动烙铁，出问题好排查
- 二极管方向别焊反（看丝印或万用表蜂鸣档）
- 矩阵编号和物理形状无关，接线只管行列
- 焊接是下午就能入门的手艺，焊坏几颗轴是学费
